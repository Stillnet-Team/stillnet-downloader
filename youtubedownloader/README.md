# Telegram-бот для загрузки YouTube

Бот принимает ссылку на одиночное общедоступное видео YouTube или Shorts,
предлагает MP4/MP3 и отправляет файл размером до 50 МБ.

## Установка на Windows

1. Отзовите ранее опубликованный токен через BotFather и получите новый.
2. Активируйте виртуальное окружение и установите зависимости:

   ```powershell
   .\venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   ```

3. Установите [FFmpeg](https://ffmpeg.org/download.html) и добавьте команды
   `ffmpeg` и `ffprobe` в `PATH`. Проверьте установку:

   ```powershell
   ffmpeg -version
   ffprobe -version
   ```

4. Задайте новый токен только в текущем терминале и запустите бота:

   ```powershell
   $env:BOT_TOKEN="НОВЫЙ_ТОКЕН"
   python bot.py
   ```

Плейлисты, приватные, возрастно ограниченные и защищённые видео не поддерживаются.
Скачивайте только материалы, на которые у вас есть соответствующие права.
